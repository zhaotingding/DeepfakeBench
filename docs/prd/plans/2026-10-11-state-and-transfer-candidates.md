## Q26-D01/v1：Q23端点的权重×BN状态与排序分解

**问题**：Q23两臂相对排名反转，与参数变化、BN运行统计变化各有什么关系？这是固定模型的状态干预，不是训练因果或新方法提点。

固定Q23 original_aux及residual_aux两臂，各自source_best和terminal全部四个原checkpoint（路径、SHA见[Q23指标](../records/Q23-T01.metrics.json)）。不跨臂换状态，不选择表现最好的一对。令θ包含LoRA及全部头参数（含BN gamma/beta），b仅为`head.1.running_mean/running_var`；`num_batches_tracked`留档，eval不参与输出。每臂计算四状态：

| 状态 | 参数 | BN统计 |
|---|---|---|
| F00 | source_best θ0 | source_best b0 |
| F01 | source_best θ0 | terminal b1 |
| F10 | terminal θ1 | source_best b0 |
| F11 | terminal θ1 | terminal b1 |

- 所有模块eval、dropout关闭、0训练更新。每个θ只计算一次Linear后/BN前激活，对同一激活应用两套BN及该θ的后续头；四个θ得到两臂八组输出。保留float32激活以供CPU重算，不改原checkpoint，不保存混合权重作为候选部署模型。
- 先用原环境32源图验实现；四个自然对角必须重放原存预测到原1e-5门槛（含视频/帧身份），失败即停止在实现/数值核验。固定源val700中央帧、源test700视频5600帧及三目标5876视频45232帧、原预处理/视频meanlogits；不缩成192后当完整结论。只读原权重和保存预测，不能更新BN来冒充eval。
- 同时记录每层LoRA有效矩阵`(alpha/r)BA`、头参数和BN统计的端点距离；不只看LoRA因子范数，更不以小梯度替代实际位移。两个端点间是多轮更新，只能描述端点漂移。

**固定分析**：对宏及逐域AUC/CE/balancedCE分别算两种条件BN效应`F01−F00`、`F11−F10`、权重效应和交互`I=F11−F10−F01+F00`。记录符号约定（AUC高为好，CE低为好），不得混合不同指标的贡献。

`φb = ((F01−F00)+(F11−F10))/2`；`φθ = ((F10−F00)+(F11−F01))/2`；恒有`φb+φθ=F11−F00`。两臂反转量R=0.03013314应复算为`(φb_res−φb_orig)+(φθ_res−φθ_orig)`。这是依赖这两个端点的代数分账，交互可使贡献抵消/大于总变化，不叫“BN解释了百分之多少因果”。

主AUC严格沿Q23原scores实现：先平均帧logits，再以float64计算`p=exp(z1−logaddexp(z0,z1))`。对每域真假概率差m=p_fake−p_real，`H(m)=1/0.5/0`（正/零/负），精确复算`ΔAUC=mean[H(m_new)−H(m_old)]`。另列logit-margin间隔；先核对其排序/并列与原概率一致，有限精度不一致时不宣称logit-margin精确重建原AUC。用分块计数报告对→错、错→对、并列、原始间隔与涉及视频集中度，真假样本对不是独立样本。沿用2000次域×类别视频配对bootstrap（seed20261011），给BN/参数分账区间；同一重采样应用全部八状态。

**决策**：若残差学生两种条件BN效应均正，且其宏AUC φb≥.005、配对95%下界>0，开放下项源域重估验证；这只是后续机制线索，不改Q23未支持结论。若效应反向、交互强或混合源指标显著恶化，报告状态兼容性，不能简单归因；若BN影响小，停止BN提点分支，本批不自动追加LoRA/头交换。

**预算/交付**：≤2 GPUh、总墙钟≤6h、CPU2线程/RSS≤8GiB，新产物含备份≤4GiB；测速确保完整面板可完成，超预算停而不扩张。交付八组预测、自然对角复现、精确分账/排序计数及区间、退出证据/中文Git/`docs/prd/records/Q26-D01.md`；0自动重试。不声称独立最终测试或普遍微小更新机制。

## 相关工作与边界
