# PRD公共训练与评测基线

当前4090公共目录与分支统一为“公共基线”。本轮公共实现源于已验收的99df1958（首批实际训练代码6560564）；后续公共代码及方法整合版本以当前HEAD和本地整理回执为准。执行前以当前目录的分支、HEAD和最终配置确认运行身份。

## 当前入口

- 公共入口：scripts/早停基线.py；公共训练、恢复、选点和评测：training/prd_fresh.py。
- 重构算子探索、多响应融合、视觉表征探索复用同一公共引擎；各自的模型、方法配置与专属预检保留在对应工作树。
- 具体实验使用以方案命名的入口；共同参数由baseline_settings构造，方法额外字段仍由各工作树提供。
- r01.machine.json只保存本机路径。旧training/config/r01/common.json中的部分默认值会被正式早停入口覆盖，不能仅凭该JSON认定生效参数。
- 旧scripts/prd_r01.py与缓存流程属于历史协议。当前默认为增强后在线重构，不把先缓存后增强视作等价替换。

## 当前可比协议

从对应预训练权重和新LoRA／分类头开始。当前CLIP基准为rank/alpha16、trainBS32/testBS64、两槽分类头；新表征或改变配置时须另立匹配对照。

FF++官方train训练、固定官方val选点；验证帧AUC严格创新高才更新最佳，持平不更新。连续5轮未改善早停，最多30轮；最终恢复最佳权重再做目标评测。主域为CDFv2、DFDC、DFD、UADFV，主指标是四域帧AUC等权平均；视频指标先平均帧概率。已有目标反馈属于开发评估。

## 使用边界

同类配置复用当前方向工作树，使用独立run-id；并发代码开发才需要额外工作树。运行中不切分支、不修改运行文件。工作树共享环境、数据、输出存储和资源锁。

公共修复先在公共基线完成必要验证，再传播到空闲方向，记录源提交和目标提交。方法实现不整批覆盖。重构算子并行的单位方向残差、绝对值残差和原图辅助监督已整合到重构算子探索；原有超分、压缩与全层激活重算保留。203本轮未操作。

训练需单独获得实验授权、认领、现场资源核验及新版本预检。本次整理仅完成CPU／静态等价验证，没有启动训练或GPU预检；旧预检的代码提交不等于当前提交。

协作规则、任务、实验正文仍以Windows本地dev为入口。29个旧gpu0/gpu1工作树及内部产物已按用户授权清理，历史记录中的旧路径不保证仍可访问；历史源码／缓存协议可按原提交追溯，Git对象也不替代已经删除的训练权重。旧主目录公共.git、当前研究工作树与共享数据／预训练权重保留。

## 重构方向整合后的方案

单位方向、绝对值残差、原图辅助监督分别使用scripts/VQGAN单位方向残差早停.py、scripts/VQGAN绝对值残差早停.py、scripts/VQGAN原图辅助监督早停.py；三项保留原GPU1与105小时训练／5小时终测上限。学习型压缩继续使用其命名入口、GPU0与全层激活重算；原图辅助使用24层CLIP的偶数层激活重算，并仅在训练添加系数1的原图辅助CE，终测只用联合主头。

历史归一化特征差、BM3D、Restormer、扩散算子及结果摘要保留用于追溯，不因此转换成新早停协议或自动启动旧队列。旧监督与补评脚本可从整合提交的源父db448cf追溯。搬迁的.state记录和既有run产物保留原代码、绝对路径与身份；其中旧launcher仅作历史证据，不直接执行，也不把新提交当成旧恢复点的同一运行身份。

并行树原有16组.state产物已原件移入重构算子探索的同名.state目录，正式prd-runs产物保持原位。历史metadata中的路径和code_commit保持原文，按本地整理回执查新位置；不把搬迁后的旧预检当作新提交的运行许可。GitHub旧协作分支codex/prd-progress已删除，实验协作仍以Windows本地dev为准。
