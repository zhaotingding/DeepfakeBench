# PRD实验操作

本技能保存PRD项目的稳定流程。任务范围、GPU、预算、截止时间、重试次数和后续批次，以当前用户授权及所属对话最新决定为准；共享表记录状态，不能授予执行权限。旧笔记中的持续研究窗口、PID、预约和单批批准均不继承。

## 选择所需证据

- 首次接入、恢复上下文、准备新实验或发布终态时，同步并读取 `origin/codex/prd-progress:PRD实验总表.md`。阶段1只读时，用可用的只读远端接口核对；需要改变本地Git引用的fetch留到已批准执行阶段。共享不可用时保留已有任务，不据旧表启动新实验。
- 普通监控只读本任务近期日志与状态。按科学问题查重、复用结果或排障时，再读取相关 `docs/prd/records/<ID>.md`、计划或服务器归档；不全文加载细表与历史。
- 训练分支中的同名表可能仅是入口。未发布的代码和证据用服务器、绝对路径与commit定位，不能构造不存在的GitHub链接。

## 启动已授权实验

1. 按科学问题、数据和训练协议查重，不能只比名称或seed。固定假设、最小对照、主判据、预算与停止条件；候选状态不等于可以执行。
2. 确认目标服务器、绝对工作树、GPU、task、实际配置和产物目录。203与4090分别管理，不能因本任务受阻而改动其他负责人任务。
3. 先中文提交相关代码和配置，保留无关改动；记录启动commit与dirty状态。更新自己的认领记录，登记负责人、资源、目录、task、启动commit和核验时间。
4. 远程push须当前用户明确授权；协作文档发布许可不扩展为训练代码发布。认领成功发布并读回同一提交后，再以现场PID/GPU、显存与本用户锁核验启动条件。冲突时重读判重，不强推覆盖。

共享引用同步与PC认证Git/bundle中转，按需读 [共享发布与归档定位](references/shared-publishing.md)。训练、代码修改或应用定时任务同时采用当轮适用的任务Skill；本技能补充PRD项目约束，不替代它们。

## 在途运行与单次检查

- 独立工作树隔离代码和索引，不隔离GPU、环境、输出或锁。运行中固定工作树，不切分支、不原地修改运行文件。实验身份以启动commit、配置和dirty记录为准，后续文档HEAD不替代它。
- 结合实际PID、cwd、GPU绑定和近期日志判断阶段。旧status、锁文件或周期progress不足以证明卡死、空闲或完成；smoke与正式进程必须区分。显存足够时能否共享由当前授权和实测峰值决定，不停止其他用户。
- 使用应用官方调度工具，根据至少一段有代表性的实际步速/完整epoch、剩余评估和归档耗时，设置明确日期、时间、时区、目标对话的下一次单次检查。已有同任务ID时沿用；不默认固定无限轮询。
- 更新后读回状态、目标对话、次数和下一运行时间。登记、实际回调、SSH成功分别记录；PC离线、应用未运行或写锁可能延迟检查。工具不可用或被拒时如实报告，不用脚本/数据库修改冒充应用调度。健康无实质变化保持安静，仅按用户通知意图报告交接、异常、完成或需决策事项。
- 终态后的暂停、删除或接续按当前授权处理，不从旧批次继承。审批、写锁和离线问题按需读 [已验证经验与边界](references/verified-pitfalls.md)。

## 完成、失败与产物复用

- 按本组协议核验正式退出码、权威completion或明确的recovered记录、完整更新/评估、选点规则、必要独立指标与配对统计、归档和result_commit；协议要求的校验也须完成。未满足前不报最终结果。
- 训练失败与归档/提交失败分开。保留failure、日志与partial；已完成计算可在授权范围内修复归档，不因此重训。正式失败重试或新批次必须有相应授权，不能复活取消队列。
- 总表每个候选/在途任务一行，领取后移入在途、完整验收后移出；详细结果由所属Agent写入专属记录，总对话汇总。旧seed、阴性、失败和取消历史保留；无实质变化不刷记录。
- 历史引用先核对完整路径、实际版本、权重与清单身份及现存副本。Git标签保存提交，不包含未跟踪大权重；软链接也不是独立备份。删除分支不能作为删除产物的依据。
- 单seed、短预算、目标域反复使用和跨机差异限制结论。目标选checkpoint不是独立测试；源选点与terminal如协议要求应全部保留，不能按赢家改判据。正交性、梯度、损失或线性可读性本身不证明因果机制、增量信息或泛化收益。数据键、随机前向和跨硬件重放的已知陷阱见按需参考。
